Invent the most useless superpower in one line: I can summon a single perfectly cooked grain of rice once a day, and it always lands three metres behind me. One grain, perfectly cooked, forever out of reach — the whole joke is naming it.

## Run it

```sh
python3 main.py
```

Writes the one-line entry to `/output/entry.txt` (108 characters, UTF-8, mode 0644).
